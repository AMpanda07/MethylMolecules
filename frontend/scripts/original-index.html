A Personal Update on Source Code

To all the amazing people who have supported my journey: Thank you so much. Your continuous encouragement and enthusiasm for Zperiod mean the world to me.

Unfortunately, I have recently discovered several blatant clones reproducing my design, content, and UI for commercial gain. To protect the integrity of my hard work, I have made the difficult decision to temporarily transition my GitHub repository to private.

Please rest assured, once this project reaches its full maturity, I plan to reintroduce open-source components for the community to learn from!

The original public repository remains available for reference, but it will be temporarily paused and no longer updated.
